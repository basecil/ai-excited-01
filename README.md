# Breach — ai-excited-01 entry

A photorealistic whale breaching up through the glass facade of a skyscraper,
shards and spray caught mid-explosion against the city skyline.

`main.py` copies the embedded artwork (`hero.jpg`) byte-for-byte to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`), creating the directory
first. Standard library only, no network, deterministic across runs.
